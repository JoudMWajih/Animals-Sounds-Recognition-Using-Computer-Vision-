# 🐾 Animal Sound Recognition using Computer Vision

## 📌 Overview
An interactive AI project that recognizes animals from images and plays their corresponding sounds.

## 🎯 Objective
To combine computer vision with interactive multimedia applications for real-time user experience.

## 🧠 Approach
- Image classification using pre-trained models
- Integration with sound playback system
- GUI interaction

## ⚙️ Technologies
- Python
- TensorFlow / Keras
- OpenCV
- Tkinter / Pygame

## 🚀 Features
- Recognizes animals from images
- Plays corresponding sounds
- Interactive user interface
